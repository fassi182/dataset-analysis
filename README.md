This repository contains the Week 1 tasks for the ML/AI Internship Program. The project focuses on data preprocessing, model building, and prediction analysis using two real-world datasets:

🏦 Bank Marketing Dataset (Binary Classification)

🏀 NBA Players Performance Dataset (Regression Analysis)

🔧 Objectives
Get hands-on experience with Python libraries: pandas, numpy, scikit-learn, matplotlib, seaborn

Apply data preprocessing and feature selection techniques

Train and evaluate classification and regression models

Analyze feature importance and model insights
